# SOC Lab 01 — Investigation Findings
## 1. Observed Pattern
Five failed login attempts occurred within approximately one minute for the same account
and source IP in this fictional scenario.
## 2. Evidence Collected
- Failed login attempts: 5
- Approximate time window: 1 minute
- Account: analyst.test
- Source IP: 203.0.113.45 (reserved for documentation examples)
- Successful login after failures: Not confirmed; further log review is required.
## 3. Analysis
The repeated failures may indicate a mistyped password, an automated process, or a
possible brute-force attempt. The available evidence does not establish the cause.
## 4. Next Investigation Steps
1. Review authentication logs after the failed attempts.
2. Determine whether any successful login occurred.
3. Check for similar activity involving other accounts or source addresses.
4. Compare the activity with expected account behavior.
## 5. Preliminary Assessment
Status: Needs further investigation.
Reason: The pattern warrants review, but no account compromise has been confirmed.
## 6. Analyst Notes
A security alert is a signal to investigate, not proof of an attack. Conclusions should be
based on verified evidence.
## 7. Lab Disclaimer
This is a fictional training exercise. No live system was accessed or investigated.
